# DIOPSIS AI – Anomaly Detection

A Proof of Concept exploring AI-based anomaly detection and predictive maintenance for DIOPSIS-insectcameras.

## Project Overview

This project researches whether historical sensor data can be used to detect abnormal behaviour and predict potential failures in DIOPSIS cameras.

The goal is to identify patterns in sensor measurements that may indicate an upcoming failure, allowing potential issues to be detected before a camera becomes inactive.

This project aims to develop a Proof of Concept demonstrating the possibilities of using AI and Machine Learning for predictive maintenance.

## Installation

### Prerequisites

- Git
- [Miniconda](https://docs.anaconda.com/miniconda/) or Anaconda

### 1. Clone the repository

```bash
git clone https://github.com/StephanCandA/student-diopsis-model-training.git
cd student-diopsis-model-training
```

### 2. Create the Conda environment

```bash
conda env create -f environment.yml
```

### 3. Activate the environment

```bash
conda activate diopsis-ai
```
